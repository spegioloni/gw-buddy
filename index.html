📥 Flottenübersicht einfügen

Markiere im Spiel die Flottenansicht (inkl. der Kopfzeile Nachrichten HH:MM:SS - TT.MM.JJJJ) und füge sie hier ein. Auswertung mit Strg+Enter. Eingabe wird lokal gespeichert.

🔌 GigraWars API

Trage API-Token und Universum ein – die Daten werden im Modus automatisch bzw. direkt per HTTPS direkt gegen die GigraWars-API geladen (die API sendet CORS-Header). Token & Einstellungen bleiben ausschließlich lokal in deinem Browser (localStorage) und werden nirgends hochgeladen.
Nur wenn du die Seite lokal per file:// öffnest, brauchst du den Proxy (START.cmd / localhost:8787).
